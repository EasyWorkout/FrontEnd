# ⚡ EasyWorkout — Treine com Inteligência

Plataforma gratuita de gestão de treinos voltada a estudantes e comunidades, desenvolvida como projeto prático da disciplina **Programação Web Front-end** (UTFPR — Cornélio Procópio).

Alinhado ao **ODS 3 — Saúde e Bem-Estar** da Agenda 2030 da ONU, o EasyWorkout democratiza o acesso a ferramentas de acompanhamento de condicionamento físico.

---

## 🎯 Funcionalidades

- Landing page apresentando o serviço e seus benefícios
- Cadastro de usuário com perfil personalizado (nível, objetivo, disponibilidade)
- Tela de gestão de treinos com planejador semanal
- Tela de execução de treino com registro de séries e cargas
- Tela de progressos com gráficos e recordes pessoais
- Tela de informações pessoais com cálculo de IMC
- Currículos dos integrantes linkados no rodapé

---

## 🗂️ Estrutura do Projeto

```
EasyWorkout/
├── index.html                     # Página principal (landing page)
├── cadastro.html                  # Página de cadastro
├── login.html                     # Página de login
├── gestao-treino.html             # Tela de gestão de treinos
├── exibicao-treino.html           # Tela de execução de treino
├── progressos.html                # Tela de progressos e recordes
├── informacoes-pessoais.html      # Tela de perfil e informações pessoais
├── style.css                      # Estilos compartilhados (tema dark)
├── Curriculo_Diego_Corte.html     # Currículo — Diego Corte
├── Curriculo_Thales_Hasegawa.html # Currículo — Thales Hasegawa
└── assets/
    ├── icons/                     # Ícones SVG
    └── images/                    # Imagens e fotos
```

---

## 🛠️ Tecnologias

- **HTML5** — estrutura semântica (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `figure`)
- **CSS3** — tema dark, variáveis CSS, Flexbox, Grid, responsivo (960px / 600px)
- **Google Fonts** — Poppins (títulos) + Inter (corpo)
- Sem JavaScript · Sem frameworks
